## 0. 视角分配原则

四页内容按 **2:1** 的比例混排两个受众的关注点：

| 受众 | 关注点 | 占比 |
|---|---|---|
| 校长 / 院领导 | 战略价值、竞争定位、知识资产沉淀、自主可控 | 2/3 |
| 教师 / 学生 | 具体能用什么、怎么上手、数据怎么进来 | 1/3 |

**分配策略**：战略叙事在前（Hero、价值柱、全宽 section），用户实用内容在后（快速入口、操作说明）。两类内容共存于同一页，领导看到战略价值，教师继续滚动看到操作入口。

**页面导航名称**（任务导向，非技术层级）：

| 文件 | 页面名 | 校长视角锚点 | 用户视角锚点 |
|---|---|---|---|
| `02-home.html` | 首页 | AI 原生教研环境 · 三大战略价值 | 快速入口（1 个区块） |
| `04-scenarios.html` | 研究范式 | 研究方式的范式转变 · 场景战略意义 | 三个具体操作场景 |
| `05-capabilities.html` | 技术底座 | 自主可控 · 知识资产沉淀 | 四大能力的用户侧说明 |
| `06-data.html` | 数据要素 | 数据资产化 · 数据不出校园 | 两条上传路径操作说明 |

## 1. 整体信息架构

### 1.1 设计前提

- 首页**以展示为主**：向领导汇报、向新用户介绍平台，同时提供用户快速入口
- 工作台**不进顶部导航**，通过头像下拉菜单进入，保持首页聚焦于展示
- 三个导航页均为**纯展示页**

## 2. 首页（02-home.html）


### 4.3 Hero 区【校长视角 · 主导】

```
// INFRASTRUCTURE

自主可控的 AI 基础设施
```

- 标题 36px，副标题两段各 16px，背景 `grid-bg`

### 4.4 四大能力区【用户视角为主 · 含校长注脚】

2×2 网格，每张卡片：图标 + 能力标题 + 用户侧说明 + 校长侧注脚（小字，`var(--text-muted)`）

**① 对话驱动分析**
- 用户侧：用自然语言描述分析需求，无需编程。平台理解金融领域语境，自动拆解任务步骤。
- 校长注脚：`降低科研技术门槛，使全体教师都能独立开展数据驱动研究`
- 标签：`DeepAgents` `LangGraph` `deepseek-v4-pro`

**② 代码自动执行**
- 用户侧：agent 编写 Python 分析脚本，在隔离沙箱中真实执行，返回计算结果与图表。pandas / numpy / matplotlib 开箱即用。
- 校长注脚：`生成的代码留存于学院服务器，形成可复用的量化研究资产`
- 标签：`Python` `pandas` `matplotlib` `Sandbox`

**③ 实时流式输出**
- 用户侧：执行过程实时可见，思考步骤、工具调用、代码输出逐条推送。断线重连自动补齐，长任务不丢失进度。
- 校长注脚：`全程可观测，每一步推理有据可查，满足学术研究的可追溯要求`
- 标签：`SSE` `实时推送` `断线重连`

**④ 安全隔离执行**
- 用户侧：每个会话独享隔离容器，代码执行不影响他人数据。支持人工介入审批敏感操作。
- 校长注脚：`院内部署，数据不经过任何商业云服务，满足学术数据保密要求`
- 标签：`gVisor` `容器隔离` `HITL`
