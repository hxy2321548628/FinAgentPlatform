// DATA SECURITY

您的数据安全

数据不出校园
部署在学院内网，所有数据存储于本地服务器，不经过任何商业云服务
用户数据隔离
每位用户独立 workspace，管理员无法查看数据内容，严格权限隔离
操作全程可审计
