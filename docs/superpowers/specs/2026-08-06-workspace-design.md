## 1. 定位与用户

**页面目标**：教师或学生输入分析问题，观察智能体自动编写并执行代码的过程，获取图表和结论。

**两类用户的核心差异**：

| | 教师 | 学生 |
|---|---|---|
| 核心诉求 | 拿到分析结论与图表 | 结论 + 看懂 agent 怎么做到的 |
| 对代码态度 | 不关心，黑盒即可 | 好奇，有学习价值 |
| 对执行过程 | 知道没卡死即可 | 希望理解每步因果 |

设计必须同时服务两类用户，不能为任一方牺牲另一方。

## 4. 主对话区

背景保留 `grid-bg`（蓝调网格纹，`opacity 0.025`），消息列表 `overflow-y: auto`，底部 padding 留给输入区。

### 4.1 消息类型总览

| 类型 | 触发事件 | 位置 |
|---|---|---|
| 用户消息 | 用户发送 | 右对齐，深蓝气泡 |
| Reasoning 折叠块 | `reasoning` 事件 | 左对齐，灰色折叠块 |
| 工具调用流 | `tool_call` / `tool_result` 事件 | 左对齐，终端单行列表 |
| Agent 正式回复 | `token` 事件 | 左对齐，白色气泡，Markdown |
| HITL 审批卡片 | `interrupt` 事件 | 左对齐，橙色边框卡片，阻断输入 |
| 思考动画 | run 开始后，首个 token 到达前 | 左对齐，三点跳动 |

### 4.2 用户消息

```
                    ┌─────────────────────────────────────┐
                    │  把 portfolio.csv 按行业分组，        │
                    │  计算各组年化波动率并画图              │
                    │                                     │
                    │  📎 portfolio.csv                   │
                    └─────────────────────────────────────┘
```

- 最大宽度 560px，右对齐
- 附件标签：`📎 文件名`，白色半透明背景
- 气泡色：`var(--brand)` 深海军蓝

### 4.3 Reasoning 折叠块

**执行中（流式展开）：**

```
┌─────────────────────────────────────────────────────────┐
│  ◉  思考中...                                            │
│                                                         │
│  先读取 portfolio.csv，了解数据结构。然后按 sector        │
│  字段分组，对每组的日收益率序列计算标准差，再乘以          │
│  √252 得到年化波动率。最后用 matplotlib 画分组柱状图...   │
│                                          [文字持续追加]  │
└─────────────────────────────────────────────────────────┘
```

- 背景 `#F7F9FC`，左边 3px `var(--border)` 竖线
- 字体 14px，`color: var(--text-secondary)`，行高 1.75
- `◉` 为旋转动画（CSS `animation: spin 1s linear infinite`）

**完成后自动折叠：**

```
┌─────────────────────────────────────────────────────┐
│  ▶  思考过程  ·  已折叠                  [点击展开]  │
└─────────────────────────────────────────────────────┘
```

- 高度压缩为 36px，点击展开/收起，切换 `▶` / `▼`
- 折叠动画 200ms ease

### 4.4 工具调用流

跟在 Reasoning 块之后，作为独立区块，**不放在气泡内**，直接排列。

```
  ✓  read_file    portfolio.csv                      0.1s
  ✓  write_file   volatility_analysis.py             0.1s
  ◉  execute      python volatility_analysis.py       ...
  ○  write_file   industry_volatility.png
```

样式规范：
- 字体：`'JetBrains Mono', monospace`，12px
- 工具名：`color: var(--action)`，固定宽度 80px（等宽对齐）
- 参数：`color: var(--text-secondary)`
- 耗时：`color: var(--text-muted)`，右对齐
- 状态图标：`○` 待执行灰色 · `◉` 执行中蓝色旋转 · `✓` 完成绿色 · `✗` 失败红色
- `execute` 工具完成后，右侧出现「查看输出」小链接，点击展开 stdout/stderr（默认隐藏）

### 4.5 Agent 正式回复

工具调用流完成后，agent 文字结论正常流式输出，样式和现有气泡一致：

- 左对齐，白色背景，`border-radius: 2px 12px 12px 12px`
- Markdown 渲染（H2/H3/p/table/code）
- 末尾有流式光标 `.cursor`（blink 动画），完成后消失

### 4.6 HITL 审批卡片

`interrupt` 事件触发后，流暂停，底部输入区**禁用**（opacity 0.4，pointer-events none），审批卡片出现在对话末尾。

```
┌──────────────────────────────────────────────────────────────┐
│  ⚠  等待您的确认                                             │
│  智能体请求执行以下操作，请审批后继续：                        │
│                                                              │
│  execute                                                     │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  python delete_old_files.py --confirm                  │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  [  ✓ 批准  ]  [  ✗ 拒绝  ]                                 │
│                                                              │
│  ── 或直接回复智能体 ──────────────────────────────────────  │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  不用删，直接保留原文件...                   [ 发送 ]  │ │
│  └────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

样式：
- 整体边框 `1.5px solid var(--status-warn)` 橙色
- 背景 `#FFFBF0`（极淡暖黄）
- `⚠` 图标色 `var(--status-warn)`
- 代码块背景 `#F7F9FC`，monospace 字体
- 「批准」按钮：`var(--action)` 蓝色实心
- 「拒绝」按钮：`var(--border)` 描边
- 直接回复区：与底部输入区同款 textarea + 发送按钮

用户操作后，卡片底部加一行操作记录（`✓ 您已批准` / `✗ 您已拒绝` / `💬 您已回复：...`），卡片变为只读不可再操作，输入区恢复。

## 5. 底部输入区

```
┌──────────────────────────────────────────────────────────┐
│  请描述您的分析需求，例如：计算各行业年化波动率并画图...    │
│                                                          │
│  [📎 上传文件]  [⏸ 暂停]              Enter发送  [➤]   │
└──────────────────────────────────────────────────────────┘
```

- `Enter` 发送，`Shift+Enter` 换行
- 上传文件：触发隐藏 `<input type="file">`，支持 `.csv .xlsx .pdf .txt`
- 暂停按钮：run 执行中才显示；点击后变「继续」
- HITL 期间：整个输入区 `opacity: 0.4; pointer-events: none`（审批卡片接管输入）

## 6. 右侧面板（320px 默认）

### 6.1 状态栏（顶部固定，不随滚动）

**执行中：**
```
● 执行中  RUN-8B3F  ·  已用时 02:14
[●●●●●●●○○○○]  62%
token  12,430 / 120,000
```

**完成后：**
```
✓ 完成  ·  用时 3m22s  ·  消耗 31,340 tokens
```

**等待审批：**
```
⚠ 等待确认  RUN-8B3F  ·  已暂停 00:47
```

- 状态点颜色：执行中蓝色旋转 · 完成绿色 · 审批橙色
- 进度条：`var(--action)` 蓝色填充，`animation: progress-pulse` 脉冲
- token 消耗：`font-family: monospace`，超过 80% 配额变橙色

### 6.2 WORKSPACE 文件树

```
// WORKSPACE

📁 /workspace
  📄 portfolio.csv             ↗ 预览
  📄 volatility_analysis.py   ↗ 预览
  📊 industry_volatility.png  ↗ 预览
  📄 report_summary.md        ↗ 预览
```

- 文件随 `tool_result` 事件**实时增量出现**（write_file 完成即追加）
- 图标按类型区分：📊 图片 · 📄 文本/代码 · 📦 其他
- `↗ 预览`：点击在面板内展开预览（图片直接显示，代码显示前 20 行 Shiki 高亮）
- 历史会话进入时：调用 `GET /threads/{id}/workspace` 初始化（**需后端补充此接口**）

### 6.3 ARTIFACTS 产物区

图片生成后（`tool_result` 显示 `.png/.jpg` 写入成功）**自动出现**，无需切 Tab。

```
// ARTIFACTS

┌─────────────────────────────────────────────┐
│                                             │
│        [industry_volatility.png]            │
│         全宽图片展示，点击放大               │
│                                             │
└─────────────────────────────────────────────┘
[ ↓ 下载图片 ]

┌──────────────────────────────────────────┐
│  📄 volatility_analysis.py        ▶ 展开 │
│  Python · 48 lines · 1.2 KB             │
└──────────────────────────────────────────┘
[ ↓ 下载代码 ]
```

- 图片点击展开全屏 Modal 查看
- 代码卡片展开后显示完整 Shiki 高亮代码块
- 多张图片按时间顺序堆叠，最新的在最上

### 6.4 STEPS 执行日志

```
// STEPS  [▼ 收起]

✓  read_file   portfolio.csv
✓  write_file  volatility_analysis.py
◉  execute     python volatility_analysis.py
   └─ stdout: Computing sector volatility...
   └─ 已执行 2.3s
○  write_file  industry_volatility.png
```

- **执行中**：自动展开，随 SSE 事件实时追加
- **执行完成**：自动折叠（标题行 + 「展开」按钮），节省空间让产物区成为视觉主角
- `execute` 工具：完成后展开显示 stdout 前 3 行，点击「查看全部」展开完整输出
- 失败的步骤：`✗` 红色，stdout/stderr 自动展开显示错误信息

## 10. 不做的事（本次原型范围外）

- 右侧面板宽度拖拽（保留，复用现有逻辑即可）
- 子 agent 嵌套展示（`subagent.*` 事件暂无样本，留空）
- `todo.updated` 事件渲染（暂无样本）
- 暗色模式（DSD 未定义色值）
- 响应式断点（DSD 全篇为固定 px，仅支持桌面浏览器）
