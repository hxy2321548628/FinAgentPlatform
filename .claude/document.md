# 文档撰写规范

---

## 一、格式

- **统一 Markdown**：所有文档用 `.md`，标题层级清晰，命令 / 代码用代码块包裹。
- **图用 Mermaid**：流程 / 时序 / 架构 / 状态图一律用 mermaid 代码块，不用截图（不可 diff、易失效）。
- **单数命名**：文件 / 目录名用单数。

---

## 二、可核对

- **绝对日期**：写具体日期（`2026-07-06`），不写"下周 / 三天后"。
- **决策留痕**：关键取舍写清"选了什么、为什么、放弃了哪个替代方案"。
- **随代码同步**：设计与实现分叉时，改文档或改代码，不留过期描述。
