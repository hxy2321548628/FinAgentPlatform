## 0. 设计前提与关键决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 工作台入口 | 从首页头像下拉菜单「进入工作台」| 工作台是全屏后台应用，不进顶部 Navbar |
| 整体布局 | 左侧深色 Sidebar + 右侧内容区，无顶部 Navbar | 专业系统调性，与首页展示页有明显密度差 |
| 导航风格 | 任务导向命名（「分析对话」而非「L2 agent」）| 符合用户认知，不暴露技术层级 |
| 智能体广场深度 | 支持教师发布（B 方案）| 方法论沉淀是平台核心价值，纯浏览太保守 |
| 管理后台范围 | 用户管理 + 注册审批 + agent 审核 + 用量看板 + 系统状态 | 最小可用，不做审计日志和复杂运营功能 |
| 注册流程 | 用户注册 → 待审批 → 管理员激活 | 内网部署，需控制访问身份 |

**样式规范（参考效果 HTML 调性，融合 DSD token）：**
- Sidebar 背景：`#0D1829`（`var(--text-primary)` 的近似深色）
- 导航项文字：`rgba(255,255,255,0.6)`，active 态：`rgba(255,255,255,0.95)` + 左侧 `3px var(--action)` 蓝色竖线 + `#1e3a5f` 背景
- 分隔线：`rgba(255,255,255,0.08)`
- 用户信息区：底部固定，头像圆形 + 姓名 + 角色标签

## 2. 总览页（/workspace）

### 2.1 页面结构

```
页面标题区：总览 · 2026-08-08 星期六
──────────────────────────────────────
[行动建议区]  ← 上下文感知，最高优先级一条
──────────────────────────────────────
[统计卡片行]  4 列
──────────────────────────────────────
[最近会话列表]        [快速入口]
左 2/3                右 1/3
```

### 2.2 行动建议区

根据当前状态动态显示，优先级从高到低：

| 条件 | 显示内容 | 操作 |
|---|---|---|
| 有 run 状态为 `running` | `◉ 分析进行中 · 新能源行业波动率分析 · 已用时 2m14s` | 「查看进度 →」跳转对应会话 |
| 有上传文件但近 7 天未分析 | `📄 portfolio_2026Q2.csv 已上传，还未开始分析` | 「基于此文件分析 →」带文件进入对话 |
| 本月 token 消耗 > 80% 配额 | `⚠️ 本月 token 已用 81%，剩余 22,800` | 「查看用量 →」跳转设置 |
| 首次进入（无任何会话）| `开始你的第一次分析` | 「浏览场景库 →」 |
| 正常状态 | 最近一条会话摘要 | 「继续分析 →」 |

**样式**：整行卡片，`var(--action-light)` 背景，左侧 `4px var(--action)` 竖线，图标 + 文字 + 操作按钮。

### 2.3 统计卡片行（4 列）

| 卡片 | 指标 | 单位 | 说明 |
|---|---|---|---|
| 本月分析 | 次数 | 次 | 当月 run 总数 |
| Token 消耗 | 已用 / 配额 | K tokens | 进度条形式 |
| 产出文件 | 总数 | 个 | outputs/ 目录文件累计 |
| Agent 调用 | 次数 | 次 | 我发布的 agent 被他人调用次数（教师）/ 我调用过的 agent 数（学生）|

卡片样式：白色背景，`var(--border)` 边框，`border-radius: 10px`，指标大字号 + Mono 字体，底部小字说明。

### 2.4 最近会话列表

5 条最近会话，每条：
- 会话标题（截断）
- 最后活跃时间
- 状态徽标（运行中 / 完成 / 失败）
- 消耗 token 数
- 点击进入对应会话

### 2.5 快速入口（右 1/3）

3 个入口卡片：
- **新建分析对话** → `/workspace/chat`
- **浏览场景库** → `/workspace/scenarios`
- **上传数据文件** → `/workspace/data`

## 3. 分析对话（/workspace/chat）

### 3.1 布局

```
┌──────────┬──────────────────────────────┬────┬───────────────┐
│          │                              │    │               │
│  左侧    │  主对话区                    │    │  右侧产物面板  │

│  列表    │                              │    │   可拖拽)     │

│          │  底部输入区                  │    │               │
└──────────┴──────────────────────────────┴────┴───────────────┘
                                           ↑
                                      4px 拖拽分隔条
```

整体 `height: 100vh; overflow: hidden`，三栏 flexbox。

### 3.2 左侧会话列表（240px）

**顶部：**
```
[+ 新建分析]  ← btn-primary 全宽按钮
// HISTORY
```

**会话列表项：**
```
┌──────────────────────────────────┐
│  新能源行业波动率分析             │  ← 标题，超长截断
│  2026-08-08  ◉ 运行中            │  ← 时间 + 状态徽标
└──────────────────────────────────┘
```

状态徽标颜色：
- `◉ 运行中`：`var(--action)` 蓝
- `✓ 完成`：`var(--status-done)` 绿
- `✗ 失败`：`#DC2626` 红
- `⏸ 等待审批`：`var(--status-warn)` 橙

hover 显示删除图标（右侧），active 会话高亮 `var(--action-light)` 背景。

### 3.3 主对话区

**消息类型（按执行顺序）：**

**① 用户消息**
```
                                    ┌──────────────────────┐
                                    │ 请分析持仓数据中各行业  │
                                    │ 的年化波动率            │
                                    │ 📎 portfolio.csv       │
                                    └──────────────────────┘
```
右对齐，`var(--brand)` 深蓝背景，白色文字，附件标签（文件名 + 回形针图标）。

**② Reasoning 折叠块**

执行中（流式展开）：
```
┌─ 思考过程 ──────────────────────────────────────────────┐
│  正在分析持仓数据结构...首先需要了解 CSV 的列名和数据格式  │
│  然后按行业分组计算年化标准差...                          │
│  ▌                                                       │
└──────────────────────────────────────────────────────────┘
```

完成后自动折叠：
```
▶ 思考过程  （点击展开）
```

颜色：`var(--bg)` 灰底，`var(--text-muted)` 文字，左侧 `2px var(--border)` 竖线，`border-radius: 6px`。

**③ 工具调用单行（终端风格）**

```
✓  read_file    portfolio.csv          0.1s
✓  write_file   volatility_analysis.py 0.1s
◉  execute      python volatility...   运行中...
```

Mono 字体，`font-size: 12px`，`var(--bg)` 背景块，无边框。状态图标：`✓` 绿 / `◉` 蓝 spinner / `✗` 红。工具名 `var(--action)` 蓝，参数 `var(--text-muted)` 灰，耗时靠右对齐。

**④ Agent 正式回复**

```
┌─ [Agent 头像] FinAgent ───────────────────────────────┐
│                                                        │
│  已完成年化波动率计算，各行业结果如下：                  │
│                                                        │
│  | 行业     | 年化波动率 | 样本数 |                    │
│  |---------|-----------|-------|                       │
│  | 金融     | 18.3%     | 2,847 |                    │
│  | 能源     | 24.1%     | 1,203 |                    │
│                                                        │
│  图表已生成并保存至 outputs/ 目录。                     │
│                                                        │
└────────────────────────────────────────────────────────┘
```

白色背景，`var(--border)` 边框，`border-radius: 2px 12px 12px 12px`，支持 Markdown 渲染（表格、加粗、代码块）。Agent 头像：`var(--brand)` 背景，白色三横线 logo icon。

**⑤ HITL 审批卡**

```
┌─ ⏸ 等待您的确认 ────────────────────────────────────────┐
│                                                          │
│  agent 即将执行：                                        │
│  delete  /workspace/raw_data.csv                        │
│                                                          │
│  [✓ 批准]  [✗ 拒绝]  [💬 直接回复]                      │
│                                                          │
│  「直接回复」展开文本框：                                  │
│  ┌────────────────────────────────────────────┐          │
│  │ 不要删除，保留原始文件                       │          │
│  └────────────────────────────────────────────┘          │
│  [发送]                                                  │
└──────────────────────────────────────────────────────────┘
```

`var(--status-warn)` 橙色左边框，`#FFFBEB` 背景，三个操作按钮行内排列。「直接回复」点击展开输入框。

**⑥ 思考动画**

三点跳动，`var(--action)` 颜色，`14px 18px` 白色气泡内。

### 3.4 底部输入区

```
┌──────────────────────────────────────────────────────┐
│  输入分析需求，或粘贴数据...                          │
│                                                      │
├──────────────────────────────────────────────────────┤
│  [📎 附件]  [已附加: portfolio.csv ×]    [Enter 发送] [▶ 发送] │
└──────────────────────────────────────────────────────┘
```

多行文本框，`Enter` 发送，`Shift+Enter` 换行。执行中时发送按钮变为 `■ 停止`（`#DC2626` 红色）。已附加文件显示为标签，`×` 可移除。

### 3.5 右侧产物面板（380px 默认，200~700px 可拖拽）

**区一：Run 状态栏（顶部固定，56px）**

```
◉ 运行中  02:14              12,430 / 120,000 tokens
[██████████░░░░]  10.3%
```

执行中：蓝色状态 + 计时器 + token 进度条。
完成后：`✓ 完成 · 用时 3m22s · 消耗 31,340 tokens`（绿色）。
等待审批：`⏸ 等待确认` 橙色。
沙箱排队：`📋 排队中 · 前面还有 2 个`。

**区二：Workspace 文件树**

```
// WORKSPACE

📁 /workspace
  📄 portfolio.csv          1.2 MB  [↓]
  📄 volatility_analysis.py 2.1 KB  [↗ 预览] [↓]
  📊 outputs/
    🖼 industry_volatility.png       [↗]
```

文件随工具调用实时增量出现（轻微入场动画）。图片文件点击展开预览（全宽显示）。代码文件点击展开 Shiki 语法高亮。每个文件右侧：预览图标 + 下载图标。图片产出时在产物面板中突出显示（全宽展示，下方显示下载按钮）。

**区三：Steps 执行日志**

执行中展开（实时追加，最新一条有 spinner）：
```
// STEPS

✓  read_file    portfolio.csv           0.1s
✓  write_file   volatility_analysis.py  0.1s
◉  execute      python volatility...
   └─ Computing sector volatility...
   └─ Processing 4,831 rows...
```

完成后折叠：
```
// STEPS ▾  展开查看  （共 16 步）
```

### 8.3 注册审批（/workspace/admin/approvals）

**待审批队列**（高优先级，在用户管理页顶部单独展示 OR 独立子页）：

```
// PENDING APPROVALS  [3 个待处理]

申请人       邮箱                院系          身份    申请时间
王明         wang@fin.edu.cn     金融学院      教师    2026-08-08 09:21
```

## 10. DSD 落地要点

### 10.1 工作台 vs 首页的视觉差异

工作台是「使用环境」，首页是「展示环境」，两者应有明显密度差：

| 维度 | 首页 | 工作台 |
|---|---|---|
| 背景色 | `var(--bg)` 浅灰 + 网格 | `var(--bg)` 浅灰，无网格 |
| Sidebar | 无 | 深色 `#0D1829` |
| 信息密度 | 宽松，大字号，留白多 | 紧凑，功能优先 |
| 装饰元素 | `deco-stamp`，Ticker | 全部去掉 |
| 字号基准 | 15-16px | 13-14px |

### 10.2 颜色规则

- 所有颜色走 CSS 变量，无硬编码
- Sidebar 内文字用白色透明度变体（不用 DSD token，因为底色太深）
- Agent 卡片、场景卡片复用 DSD §10 的 `.research-card` 样式
- 状态徽标严格用 `var(--status-done)` / `var(--status-active)` / `var(--status-warn)`

### 10.3 动效

遵循 DSD §13 动效规范：
- 按钮 hover：150ms ease
- 卡片 hover：200ms ease
- 右侧面板拖拽：无动画，直接跟随
- 文件树新文件出现：`card-enter` 400ms ease-out
- HITL 审批卡：从下方 slide-in，`transform: translateY` 300ms ease-out
