SECTION 01 · BRAND
品牌 定位
Intelligence-Minimal（情报极简风）——整体气质是「冷静、可靠的高技术感」，面向需要做专业分析决策的用户，传递分析深度、数据可信、系统专业的品牌调性。
STYLE NAME
Intelligence
Minimal
情报极简风，以深海军蓝作为锚色，冷灰调底色，配合工程 / 终端美学的细节装饰。不追求视觉冲击，而是传递分析深度、数据可信、系统专业的品牌调性。
CORE KEYWORDS
深海军蓝 冷灰底色 报告感排版 装饰克制 数据化视觉
TARGET AUDIENCE
金融学院教师。对分析结果准确性、过程可追溯与系统稳定性有较高要求的教学与研究用户群体。

COLOR USAGE RULES · 配色原则
75% 冷灰无色系 + 25% 深海军蓝调：品牌色不应超过页面视觉重量的四分之一，确保「冷静」的整体气质。
--action（#1749C4）仅用于可交互元素：按钮、链接、选中态。不用于纯装饰性色块。Hero 大标题是例外，可大面积使用。
严禁引入暖色系作为主调：红、橙、黄系颜色仅限警告状态（--status-warn），且每个页面使用不超过 2 处。
不使用渐变作为主视觉：渐变仅用于细节装饰（如封面背景光晕）。主要内容区域保持扁平色块。

SECTION 08 · MOTION
SECTION 08 · MOTION
动效 规范
装饰性动画慢而优雅，交互反馈快而精准。不使用弹跳、旋转等夸张动效。所有运动感服务于「系统正在思考与工作」的感知，而非娱乐化炫技。
场景 属性 时长 缓动函数 备注
按钮 hover background, color 150ms ease 交互反馈，快而精准
输入框 focus border-color, box-shadow 200ms ease focus ring 展开
卡片 hover border-color, box-shadow 200ms ease 边框提亮，阴影加深
卡片入场 opacity + translateY(16px→0) 400ms ease-out 滚动进入视口时触发
终端光标闪烁 opacity 0↔1 1.1s step-end, infinite Hero 标题末尾
Ticker 滚动 translateX 35s linear, infinite 内容复制两份实现无缝
导航 active 切换 background, color 200ms ease 药丸样式切换
时间戳更新 JS textContent 替换 每 60s — 无过渡，突然切换

SECTION 10 · PRINCIPLES
设计 原则
七条核心设计原则，是所有视觉决策的终极依据。当设计方案存在争议时，以原则为准则进行评判。
✓ DO · 应当做到
留白即设计：大量空白让核心内容「呼吸」，padding 充足，不拥挤。
深海军蓝定调：用 #0B2E5C 传递可靠、权威、专业的学术机构气质。
冷色系贯通：所有灰色带蓝色底调（#5A6A7E、#8E9BB0），而非中性灰。
终端美学点缀：等宽字体、全大写标签、网格底纹、实时时间戳、光标闪烁。
数据即设计：用数据表格、状态徽章、进度指标传递分析系统的专业感。
排版建立层次：字号跨度大（11px~56px），层级清晰，无需依赖颜色区分。
✕ DON'T · 严格禁止
严禁引入暖色系（红、橙、黄）作为主调，仅限警告状态使用。
不使用渐变作为主视觉，仅用于细节装饰（如封面光晕）。
--action 色不用于纯装饰，仅限可交互元素和 Hero 标题。
不用中性灰（如 #888888），所有灰色必须含蓝色底调。
背景装饰 opacity 不超过 0.16，装饰不能抢夺内容视线。
不做弹跳、旋转、放大缩小等夸张动效，一切动效服务于功能感知。
